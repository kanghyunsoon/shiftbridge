작성/완료일: 2026-10-26. 답변은 사용자가 전달했다. 에이전트가 관리자에게 직접 메시지를 전송하지 않았다.

## MDQ-001 — 취소 LOT의 보류 미확인과 확정 후속 업무가 겹칠 때

- [x] 사용자를 통해 해당 질문에 대한 관리자 답변 수신
- [x] 관리자 최종 표시 기준 기록
- [x] D06·FR-019/025·LT-015/017·기획/지침·AC-035에 답변 반영
- [x] 변경 영향 범위의 문서 기대 결과 재검토

상태: 완료. 구현·실행 테스트 완료를 의미하지 않는다.

### 질문

취소된 LOT의 보류 수량이 공란이지만 최근 24시간 승인된 후속 확인 또는 지속 관찰 메모가 해당 LOT에 직접 연결되고 설비도 일치하면, 후속 업무와 보류 상태를 어떻게 표시해야 하는가?

### 관리자 확정 답변

- 메모 기반 인계 대상 확정, 후속 업무 있음.
- 보류 수량은 미확인, 보류 수량 관련 후속 확인 필요성은 미확정.
- LOT 전체에 후속 확인 여부 미확정을 붙이지 않음.
- 조치 완료는 미확정이며 메모 연결만으로 긴급을 확정하지 않음.
- LOT 스냅샷과 직접 연결된 메모를 함께 근거로 제공.
- 보류 수량이 나중에 0으로 확인돼도 유효한 메모의 후속 업무가 남으면 인계 유지.

후속 업무 존재·인계 여부·보류 수량·보류 관련 확인 필요성·조치 완료·긴급도를 독립적으로 표시한다. 기존 기간/연결 관계 기준은 유지한다.

반영 문서: [D06](clarifications.md), [LOT 상세](requirements/03-lot-and-quality.md), [변경 영향 검증](validation-d06.md). 미결 관리자 질문은 없다.
