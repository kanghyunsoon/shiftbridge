# 브라우저/판정 경계 계약

- `parseDataset(files)`는 파일명→문자열 또는 읽기 오류를 받아 rows/inputIssues를 반환한다. 원본 쓰기 없음.
- `buildHandover(dataset, cutoff)`는 명시 KST시각을 받아 정렬된 미해결·LOT업무·관련메모·품질·근거를 반환한다. DOM/network현재시각 의존 없음.
- `buildSummary(result, mode='compact')`는 같은 결과를 간결/전체(`full`) 텍스트로 변환한다. 간결은 영역별5건과 잔여안내, 전체는 모든항목/관련메모/파일위치다. 두 모드 모두 이력한계·부분결과·판단상태·원본ID 포함.
- UI는 cutoff와 파일 재선택 시 새 결과를 원자적으로 교체하고 이전 상세를 비운다.
- UI의 모든 원본 문자열은 텍스트로 이스케이프해 렌더링한다. 업무ID/메모의 HTML을 실행하지 않는다.
- 필수 영역: 우선알람 / 생산·현장업무 / 상태·데이터확인. 선택 항목의 근거와 요약을 열 수 있어야 한다.
- 클립보드 실패시 실패안내와 선택/복사 가능한 원문을 제공한다.
- 추가 외부 업무 API나 데이터 전송 없음. localhost서버는 정적파일 읽기만 제공한다.
- 입력 읽기는 마지막 요청만 일괄 반영하며 개별 파일 실패는 null 입력 범위로 보존한다. 오래된 읽기의 완료/실패가 새 상태를 덮어쓰면 안 된다.
- 계산 실패 시 이전 결과/상세/요약 복사를 제거한다. 비동기 복사의 성공/실패 안내는 같은 요약 요청 세대에서만 반영한다.
- `_sources`는 내부 출처용 예약 열이므로 동명 CSV 열은 입력 오류로 설명한다. 그 밖의 원본 추가 열은 중복 비교와 원본 표시에서 누락시키지 않는다.
