# D06 승인 반영 — 변경 영향 범위 재검증

작성일: 2026-10-26. 근거: 사용자가 전달한 생산운영팀 교대 책임자의 D06 최종 답변.
상태: 변경 문서의 의미·연결·수용 기대값 검토 완료. 제품 구현/실행 테스트 미수행.

## 범위

이번에는 취소 LOT의 확정 메모 업무와 보류 미확인 상태가 겹치는 조건, 보류0 전환, 화면/요약 표시만 확인했다.
이전 validation-report.md에서 검증한 교대 시각·알람·중복·재발·메모 4분류·원본 CSV 집계는 재검증하지 않았다.
이전 통과 판정은 변경 없는 부분의 근거로 재사용하고 D06로 보류됐던 체크리스트 4항목만 다시 평가했다.

## 변경 조건의 논리 대조

| 조건 | 인계/업무 | 보류·품질 | 완료/긴급 | 근거 |
|---|---|---|---|---|
| CANCELLED + 편입 조건 충족 메모 + hold NULL | 메모 기반 인계 확정·후속 업무 있음 | 보류 미확인·보류 관련 확인 필요성 미확정 | 조치 완료 미확정, 메모만으로 긴급 확정 안 함 | 해당 T의 LOT + 메모 |
| 위 LOT의 이후 가용 hold=0, 유효한 메모 업무 유지 | 메모 사유로 인계 유지 | 보류 미확인 표시는 해소, 0과 NULL 구분 | 조치 완료 자동 확정 안 함, 긴급 승격 안 함 | 이후 T의 LOT + 메모 |
| 같은 LOT가 업무/데이터 목록에 동시 표시 | 업무는 확정 상태로 유지 | 데이터 확인 항목과 연결 | 전체 후속 여부 미확정으로 바꾸지 않음 | 고유 LOT는1개, 근거는 양쪽에서 조회 |

최근24시간·직접 LOT 참조·설비 일치는 기존 승인 조건이며 이번 답변으로 변경하지 않는다. 보류0만으로 제거하지 않는다는 기준을 메모 기간 무제한 연장이나 새 완료 관리 기능으로 확대하지 않았다. 후속 근거가 없는 취소 LOT와 승인된 후속 업무가 있는 LOT를 같은 규칙으로 덮어쓰지 않는다.

## 수용 시나리오 변경

- AC-035: 관리자 답변 대기였던 기대값을 확정했다.
- AC-038: 보류 NULL→0 이후에도 유효한 메모 인계 유지.
- AC-039: 업무 확정·보류 미확인·보류 관련 필요성·완료·긴급을 목록/상세/요약에 독립 표시하고 중복 집계 금지.
- 기존 AC-001~034/036~037은 재실행·재검증하지 않았다. 입력 CSV도 다시 읽지 않았다.

## 문서 품질 상태와 한계

D06에 연결된 미해결 표시·요구 의미·분기 기대값·수용 조건 4항목을 이번 답변으로 해소했다.
체크리스트는 기존 통과12개 유지 + 이번 해소4개 = 16/16이다. 모든 항목을 처음부터 다시 검증했다는 뜻이 아니다.
기능 요구35개·성공 기준5개는 유지하고 수용 시나리오는37개에서39개로 늘었다. AGENTS는83줄로 유지했다.
현재 확인된 제품 업무 결정의 관리자 답변 대기는 없다. 정식 constitution 비준일과 이후 기술 계획은 별도 범위다.

문서의 내용/기대 결과가 일치한다는 검토이며 작동 보장은 아니다. 별도 예외 자료와 실제 UI에서 AC-035/038/039를 실행하는 검증은 구현 후 필요하다. 정식 speckit-analyze 실행이나 전체 회귀 테스트 완료로 표현하지 않는다.
