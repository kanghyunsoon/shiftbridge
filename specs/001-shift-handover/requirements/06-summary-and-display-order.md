# 06. D07 승인: 간결/전체 요약과 표시 순서

근거: 2026-10-26 사용자가 전달한 생산운영팀 교대 책임자의 최종 결정. FR-036~042를 정밀화한다. 이 문서가 기존 요약 분량/미정 정렬 설명보다 우선한다.

## 요약 범위

- SU-001: 요약을 열 때 간결 모드가 기본이다. 간결/전체 상세를 각각 조회하고 현재 모드를 복사한다. 교대/입력 재계산 후 상세와 요약은 같은 T의 새 결과를 사용한다.
- SU-002: 간결 요약은 확정 미해결 알람 5건, 생산/현장 통합 업무 5건, 데이터 확인 5건까지다. 없는 영역을 다른 영역으로 채워 5건을 넘기지 않는다.
- SU-003: 영역별 전체 대상 수·표시 수·잔여 수를 정확히 표시한다. 생략된 ID 전체는 나열하지 않고 `그 외 N건 — 전체 상세 화면에서 확인`을 쓴다. 검색/설비 필터가 아닌 선택 T 전체 판정 결과를 요약하며 이를 안내한다.
- SU-004: 각 항목에 ID·상태·사유·다음 조 확인 사항·관련 원본 ID를 넣는다. 알람 instance/event, LOT ID/revision/편입 메모 ID, 현장 note ID, 품질의 관련 원본 ID를 사용한다. 부분 입력/이력 한계를 포함한다.
- SU-005: 전체 상세에는 모든 인계 LOT·독립 현장 업무·관련 최근/과거 메모·확인 항목과 사유·원본 ID/파일 위치를 보존한다. 전체 화면의 근거 버튼으로 원본 필드를 열 수 있다. 간결 생략 때문에 원본을 삭제하지 않는다.
- SU-006: 간결 요약은 1~2분 읽기를 목표로 한다. 실제 독자 읽기 시간은 관리자 확인 전 미검증이다. 긴 원문을 15개 항목 제한의 예외로 삼지 않는다.

## 생산/현장 통합 업무 정렬

| 순위 | 조건 |
|---|---|
| 1 | hold_qty > 0 LOT |
| 2 | IN_PROGRESS LOT |
| 3 | 승인 메모 편입 조건을 만족한 후속 확인/지속 관찰 LOT |
| 4 | 최근 24시간의 그 외 승인 후속 확인/지속 관찰 메모 업무 |

- SU-010: LOT는 여러 조건에 해당해도 최고 순위 한 건으로 두고 나머지 사유를 유지한다. 유효하게 해당 LOT 업무에 반영된 메모는 동일 업무로 재편입하지 않는다. 관계 불일치 메모는 LOT 편입 없이 원문 요청 자체를 현장 업무로 유지한다.
- SU-011: 같은 순위는 각 항목의 최신 확인 가능 시각이 이른 순이다. LOT는 선택 스냅샷 updated_at과 실제 편입에 쓰인 메모 created_at 중 최신 시각, 독립 메모는 created_at을 사용한다. 참고/과거 근거 확장이나 정적 설비 메타데이터는 업무 시각을 바꾸지 않는다. 동일 시각은 ID를 안정 보조 정렬로 쓴다.
- SU-012: 동일 설비의 확정 미해결 HIGH 사건 ID를 LOT 관계로 표시하며 피해/인과 추정은 하지 않는다. 보류/진행/현장 요청을 화면에서 구별한다. 이 순위는 표시 순서다.

## 알람/데이터 확인 정렬

- SU-020: 알람은 HIGH→MEDIUM→LOW, 지속시간 내림차순, 발생 시각 오름차순이다. 같은 T에서는 지속시간 동률과 발생 시각 동률이 일치하며 최종 ID는 표시 안정성만 위한 보조키다.
- SU-021: 데이터 확인 순위는 (1) 알람 상태를 모순되게 하는 충돌/전환 모순 (2) LOT 명백 수량 모순/최고 revision 충돌 (3) 필수 수량·상태 누락 (4) 설비/LOT/메모 관계 불일치 (5) 그 외 해석 불가다. 한 확인 항목에 여러 사유가 있으면 최고 순위를 쓰고 모든 사유를 유지한다. 고아 해제나 심각도 정보 미확인은 충돌이 없다면 기타 확인으로 유지한다.
- SU-022: 같은 유형은 판정에 사용한 당시 가용 원본의 확인 가능 시각 중 최신 값이 최근인 순이다(알람 received_at, LOT updated_at, 메모 created_at). 가용 시각이 없는 기본정보는 미확인으로 남기고 동일 유형의 시각 확인 항목 뒤에 둔다. 같으면 ID를 안정 보조 정렬로 쓴다.
- SU-023: 데이터 확인과 실제 미해결 알람은 다른 영역이다. 전체 화면과 두 요약 모드는 같은 정렬 모델을 사용한다.

## 브라우저 수용 확인

1. 초기 화면에서 최우선 미해결 HIGH를 찾는다.
2. 보류/진행 LOT와 현장 요청을 구별한다.
3. 선택 항목에서 이벤트·LOT·메모 원본과 파일 위치를 연다.
4. 기본 간결 복사에서 T·대상·사유·확인 사항·근거 및 잔여 수를 확인한다.
5. 데이터 확인이 미해결 설비 알람과 별도 영역임을 확인한다.

수행 증거를 기록하되 최종 현장 사용성 승인은 관리자가 실행 결과/화면을 본 뒤 결정한다.
