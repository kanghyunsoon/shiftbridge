# 04. 메모·후속 업무·연결 관계 명세

관련 대표 요구: FR-023~FR-027, FR-029~030. 기획: 조건 D. 관리자 승인 12종과 4분류 반영.

## 기간과 완료 여부

- NT-001: T까지 가용한 `(T-24시간,T]` 메모를 기본 목록에 제공한다. 정확히 24시간 전은 제외한다(D05 확정).
- NT-002: 더 오래된 메모는 현재 미해결 알람·인계 대상 LOT의 관련 근거에서 조회한다.
- NT-003: 오래된 메모만으로 완료·보류 0 LOT를 신규 인계하지 않는다(D01).
- NT-004: 모든 메모의 조치 완료 여부는 미확정으로 유지한다. 문구·나이·분류 승인으로 실제 완료를 추정하지 않는다.
- NT-005: 기본 노출 종료, LOT 편입 사유 종료, 실제 조치 완료는 서로 다른 개념이다.

## 승인된 4분류

| 성격 | 업무 의미 | 인계·표시 | 조치 완료 |
|---|---|---|---|
| 후속 확인 | 명확한 확인/점검/조치 요청, 확인 대기 | 후속 업무 인계 | 미확정 |
| 지속 관찰 | 관찰 중이거나 지속 추적 필요 | 관찰 업무 인계 | 미확정 |
| 참고 정보 | 현황/과거 사실 전달 | 참고 및 관련 근거, 메모만으로 LOT 신규 편입 금지 | 미확정 |
| 분류 확인 필요 | 요청/기록/완료 의미 불명확 | 원문과 후속 요청 여부 확인 필요 표시, 메모만으로 LOT 신규 편입 금지 | 미확정 |

- NT-010: 단순 키워드·외부 AI로 성격을 확정하지 않는다. 요청과 완료 문장의 확인 단어가 같아도 동등 취급하지 않는다.
- NT-011: note-classification-proposal.md의 입력 12종 및 별도 명시 승인 예시의 원문별 분류·다음 조 확인 사항·승인 근거를 적용한다. 파일명은 기존 경로를 보존한 것이며 내용은 확정표다.
- NT-012: 후속 확인은 N01/N02/N04/N09/N10/N11, 지속 관찰은 N03/N05/N06, 참고 정보는 N07, 분류 확인 필요는 N08/N12다.
- NT-013: N11은 자료 누락 여부 확인 필요다. 자료 누락을 확정하거나 원본 보완을 자동 수행하지 않는다.
- NT-014: N08/N12의 분류 확인 필요는 승인된 결과다. 승인 대기로 되돌리거나 정비/일정 확인 완료라고 표시하지 않는다.
- NT-015: 실제 입력 표나 별도 명시 승인 예시에 없는 미등록·모호 문구는 분류 확인 필요로 제공한다. `정비 결과 확인 요청`은 관리자가 이미 후속 확인 예시로 제시했으므로 미등록으로 취급하지 않는다. `정비 결과 확인 완료`는 확인 키워드만으로 같은 분류/조치 완료를 확정하지 않는다. 새 의미가 업무 판정을 바꾸면 사람에게 확인한다.
- NT-016: 화면·상세·요약은 분류, 확인할 내용, 분류 근거, 조치 완료 여부, 관계 검증 상태를 구분해야 한다.

## 연결 규칙

- NT-020: lot_id 직접 참조와 equipment_id 동일 관계를 구분한다.
- NT-021: 메모 설비와 가용 LOT 설비가 다르면 각각 보존하고 연결 관계 확인 필요를 표시한다. 4분류와 독립된 경고다.
- NT-022: 불일치 메모는 표시하되 그 메모만으로 LOT를 신규 인계하지 않는다(D02). 기존 진행/보류 사유는 유지한다.
- NT-023: 관계 확인·승인·편집 기능은 이번 MVP에 없다. 앱이 관계를 임의 승인하지 않는다.
- NT-024: 같은 설비 메모를 특정 알람의 원인이나 조치 완료 증거로 단정하지 않는다.
- NT-025: T에 LOT 상세가 가용하지 않으면 참조 ID와 정보 미확인을 표시하고 미래 값을 가져오지 않는다.
- NT-026: 생산 시작 이전 메모는 사전 요청일 수 있다. 시간 차이만으로 삭제하거나 원인 확정하지 않는다.

## 편입 순서와 순환 방지

1. 알람 상태와 최신 LOT의 진행/보류 등 독립 인계 사유를 먼저 정한다.
2. 최근 가용 메모의 후속 확인/지속 관찰 분류와 직접 LOT ID·설비 일치가 확인되면 메모 기반 신규 인계 사유로 적용한다.
3. 확정 대상에 대한 오래된 관련 메모와 참고 정보를 근거로 확장한다.
4. 3번의 근거 확장이 신규 LOT 편입을 다시 유발하면 안 된다. 참고 정보가 실제 미해결 문제의 해결을 의미하지도 않는다.

## 수용 예

1. Given 30시간 전 요청뿐인 완료·보류 0 LOT, When T 조회, Then 메모만으로 신규 LOT 인계하지 않으며 완료로 판단하지 않는다.
2. Given 같은 오래된 메모가 현재 진행 LOT에 연결됨, When 근거 열기, Then 원문을 확인할 수 있다.
3. Given 최근 후속 확인/지속 관찰 메모의 설비 불일치, When 목록 조회, Then 메모·불일치는 표시하되 해당 메모만으로 LOT 편입하지 않는다.
4. Given N03/N05/N06, When 분류 조회, Then 지속 관찰로 표시하고 다음 조 관찰 내용과 완료 미확정을 제공한다.
5. Given N08/N12, When 분류 조회, Then 분류 확인 필요·후속 요청 여부 확인 필요이며 원문을 제공하고 완료로 처리하지 않는다.
6. Given N11, When 인계 조회, Then 후속 확인으로 자료 누락 여부 확인 필요를 표시하되 실제 누락으로 확정하지 않는다.
7. Given N07, When 참고 조회, Then 참고 정보로 표시하고 기존 미해결/LOT 근거에 연결하되 해결을 의미하지 않는다.
8. Given 미등록 문구, When 분류 조회, Then 분류 확인 필요로 두고 키워드로 요청/완료를 확정하지 않는다.
