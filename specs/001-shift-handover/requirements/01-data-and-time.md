# 01. 데이터·교대 시점 명세

관련 대표 요구: FR-001~FR-006, FR-031~FR-033. 기획: 조건 A, 입력 데이터.
표시 규칙의 상태는 확정 / 업무상 가정 / 결정 대기로 구분한다.

## 입력과 출처

| 규칙 ID | 요구 | 상태 |
|---|---|---|
| DT-001 | equipment, alarm_catalog, alarm_events, lot_snapshots, operator_notes CSV를 사용한다. | 확정 |
| DT-002 | 파일명, 원본 위치, 원본 값, 업무 ID, revision을 보존하고 가공 결과에서 출처로 이동 가능하게 한다. | 확정 |
| DT-003 | 원본 수정·누락값 보정·없는 과거 이력 생성은 금지한다. | 확정 |
| DT-004 | 행 순서는 발생 순서가 아니다. 같은 입력·T·확정 규칙은 같은 업무 판정을 내야 한다. | 확정 |
| DT-005 | 날짜/수량/식별자가 읽히지 않으면 정상값으로 대체하지 않고 확인 불가 이유를 제공한다. | 확정 원칙 |
| DT-006 | 입력 누락/파싱 실패 시 읽을 수 있는 부분을 제공하고 불완전 상태·오류 범위를 명시한다. 읽지 못한 부분은 0/정상으로 바꾸지 않는다. | 사용자 확정 D04 |

## 시점 정의

| 규칙 ID | 요구 |
|---|---|
| DT-010 | T는 KST 08:00 또는 20:00이며 초기 기본값은 현재 KST에서 가장 최근에 지난 교대다. |
| DT-011 | 알람은 received_at ≤ T, LOT는 updated_at ≤ T, 메모는 created_at ≤ T 조건으로 가용 기록을 정한다. |
| DT-012 | LOT/메모 시각은 가용 시각의 업무상 가정이다. 실제 수신 시각 보장이라고 표현하지 않는다. |
| DT-013 | 시점 제한 후 중복/충돌/상태/revision을 판정한다. 미래 행은 과거 충돌 판단에도 사용하지 않는다. |
| DT-014 | 상세·연결 후보·상태·건수·복사 요약은 동일한 T에 종속된다. |
| DT-015 | 오래된 미해결 사건, 진행/보류 LOT는 전체 가용 이력에서 복원한다. 24시간 필터로 먼저 자르지 않는다. |
| DT-016 | 최근 24시간은 `(T-24시간,T]`다. 정확히 24시간 전 기록은 제외하고 T 자체는 포함한다. 사용자 확정 D05. |
| DT-017 | 알람 수신 가능 여부와 발생 시각 순서를 구분한다. 사건 지속시간은 유효 발생 시각과 T를 기준으로 한다. |
| DT-018 | 가용 시각은 T 이전인데 발생/생산 시각이 미래인 모순 기록은 정상 사실로 단정하지 않는다. |

## 과거 조회와 이력 한계

- DT-020: `제공 이력 이전 상태는 확인 불가`를 화면·복사 요약에 표시한다.
- DT-021: 미해결 건수는 `제공 기록에서 확인된 미해결`로 표현한다.
- DT-022: 2026-10-18 이전 상태를 보장할 수 없고 알람은 10/18 19:00부터 기록된다. 더 이른 상태를 추정하지 않는다.
- DT-023: 데이터가 없다는 사실을 공장 정상·실제 업무 0건과 동일하게 표현하지 않는다.
- DT-024: 선택 T의 최신 가용 시각만 해당 시점 근거에 사용한다. 전체 파일의 미래 최대 시각을 과거의 확인 가능한 사실처럼 표시하지 않는다.
- DT-025: 파일 끝 이후 조회에서도 수집 완료나 최신 상태를 보장하지 않는다. 기록이 없어서 상태 갱신이 안 된 것과 실제 지속 상태를 구분하는 한계를 알린다.

## 수용 예

1. Given 19:57 해제가 20:08에 수신됨, When T=20:00, Then 그 해제는 상태·상세·요약 어디에도 당시 근거로 사용되지 않는다.
2. Given LOT의 첫 기록이 09:09 가용, When T=08:00, Then 미래 LOT 상태를 보이지 않는다. 가용 메모의 lot_id 자체는 보존한다.
3. Given 과거 기준 결과가 생성됨, When T 이후 수신된 충돌 행을 입력에 추가함, Then 과거 결과는 바뀌지 않는다.
4. Given 한 주 이전 발생한 미해결 사건이 가용함, When 최신 교대를 조회함, Then 24시간 밖이어도 인계에 남는다.

## 운영 입력의 미확정점

부분 결과는 읽을 수 있는 근거 범위만 표현한다. 필수 열이 없는 자료를 추정 복구하거나 누락 사건을 생성하지 않는다. 상태 계산이 불가능한 영역은 확인 불가로 보존한다. 가용 시각 자체가 해석되지 않는 행을 특정 과거 시점의 현장 사실로 편입하지 않는다. 입력 검증 오류와 T에서 확인된 업무를 구분한다. 구체적 파일 선택 UI와 로컬 읽기 방식은 기술 계획에서 검토하며 외부 서비스·저장소를 이 문서에서 확정하지 않는다.
