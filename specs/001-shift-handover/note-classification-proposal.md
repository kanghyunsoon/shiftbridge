# 현장 메모 12종 확정 분류표

승인 반영일: 2026-10-26. 근거: 생산운영팀 교대 책임자의 추가 11종 최종 승인과 기존 확인 대기 문구 승인 1종.
상태: 분류 승인 완료. 파일명은 기존 링크 보존을 위해 유지하며 현재 내용은 추천안이 아닌 승인 명세다.

## 승인된 4분류

| 분류 | 의미 | 인계 처리 | 조치 완료 |
|---|---|---|---|
| 후속 확인 | 명확한 확인·점검·조치 요청 또는 확인 대기 | 확인할 업무로 인계 | 미확정 |
| 지속 관찰 | 관찰 중이거나 계속 추적할 업무 | 관찰할 업무로 인계, 후속 확인과 성격 구분 | 미확정 |
| 참고 정보 | 현황 공유·과거 업무 사실 전달 | 참고 표시, 관련 기존 인계 대상의 근거로 연결 | 미확정 |
| 분류 확인 필요 | 요청·기록·완료 의미를 문장만으로 구별 불가 | 원문과 후속 요청 여부 확인 필요 표시, 임의 행동/완료 확정 금지 | 미확정 |

분류 승인 완료와 조치 완료는 다르다. 분류 확인 필요도 관리자 승인된 처리 상태이며 승인 요청이 아직 남았다는 뜻은 아니다.

| ID | 원문 | 전체 파일 행 수 | 확정 분류 | 다음 조 확인 사항 | 분류 근거·주의 |
|---|---|---:|---|---|---|
| N01 | 출하 일정 영향 여부 확인 | 13 | 후속 확인 | 실제 출하 영향 발생 여부 | 관리자 승인. 영향이 발생했다는 확정 아님. |

| N05 | 장비 상태 추이 확인 요청 | 9 | 지속 관찰 | 장비 상태 변화 추이 | 관리자 승인. 지속 추적 업무로 성격 구분. |

위 행 수는 입력 전체 90개 메모의 분석 규모이며 특정 교대의 인계 건수가 아니다. 전체 문구 분류 합계는 후속 확인 53행, 지속 관찰 23행, 참고 정보 4행, 분류 확인 필요 10행이다. 실제 표시/LOT 편입은 교대 T·가용 시각·기간·관계 조건을 별도로 적용한다.

## 명시적 분류 적용과 예외

- 12종 원문과 분류 근거를 관리한다. 단어 포함 여부로 의미를 확정하거나 외부 AI 분류기를 만들지 않는다.
- 별도 명시 승인 예시 E01: `정비 결과 확인 요청` → 후속 확인. 다음 조 확인 사항은 정비 결과이며 조치 완료는 미확정이다. 관리자가 앞선 답변에서 후속 확인 필요 예시로 직접 제시했다. 실제 입력 12종에는 없어 위 90행 분석 수치에는 더하지 않는다.
- `정비 결과 확인 완료`는 E01과 다른 문구이며 분류 확인 필요로 둔다. 완료 단어만으로 조치 완료를 확정하지 않는다. 실제 입력의 `정비 결과 기록 확인`(N08)도 E01과 달라 승인된 분류 확인 필요를 유지한다.
- 미등록·판단 어려운 문구는 분류 확인 필요로 표시하고 원문을 보존한다. 실제 요청·완료 의미는 필요 시 사람에게 확인한다.
- 모든 메모의 조치 완료 상태는 미확정이다. 참고 정보나 분류 승인 완료를 업무 완료로 바꾸지 않는다.
- 분류·조치 완료·설비/LOT 연결 검증은 별도 상태다. 연결 불일치는 분류와 무관하게 연결 관계 확인 필요를 유지한다.

## LOT 신규 인계 조건

후속 확인과 지속 관찰은 모두 인계 대상 성격이다. 메모만으로 LOT를 신규 편입하려면 `(T-24시간,T]`의 가용 메모, 직접 LOT 참조, 당시 가용 LOT와 설비 일치를 모두 충족해야 한다. 설비 불일치나 LOT 미확인이면 메모·확인 필요를 표시하되 그 메모만으로 LOT를 신규 편입하지 않는다.

참고 정보·분류 확인 필요 메모만으로 완료·보류 0 LOT를 신규 인계하지 않는다. 이미 진행/보류 등 독립 사유가 있는 LOT는 해당 사유로 인계한다. 오래된 메모는 기존 인계 대상의 관련 근거로 조회할 수 있으나 완료로 처리하거나 새 LOT 편입을 순환 유발하지 않는다.
