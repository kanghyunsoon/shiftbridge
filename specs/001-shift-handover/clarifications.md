# 결정·질문 기록

작성일: 2026-10-26. 이 문서는 승인 대기와 승인된 답변을 구분한다. 무응답은 승인하지 않는다.
모든 결정은 대표 spec의 Clarifications와 영향 상세·기획·지침·수용 기준에 동기화한다.

## D01 — 오래된 요청으로 LOT 신규 편입

- 상태: 사용자 답변 반영.
- 질문: 24시간보다 오래된 명시적 요청만으로 완료·보류 0 LOT를 신규 인계할 것인가?
- 사용자 답변: “교대범위가 12시간 단위니까 최근 24시간을 기준으로 잡아도 되지않을까?”
- 반영: 신규 메모 기반 LOT 편입에는 최근 24시간만 사용한다. 오래된 메모는 현재 독립 인계 대상의 관련 근거로 유지한다. 최근 범위에서 제외됨은 실제 조치 완료를 의미하지 않는다.
- 영향: FR-023~FR-027, NT-001~005, LT-013/015, AC-019/020.

## D02 — 메모와 LOT 설비 불일치

- 상태: 사용자 확정.
- 답변: “메모는 표시하되 LOT 편입은 관계 확인 후 적용”.
- 반영: 불일치 메모 자체와 원본 연결은 보존하되 그 메모만으로 LOT를 신규 편입하지 않는다. 진행/보류 등 독립 사유는 유지한다. 관계 확인 기능은 MVP에 없어 앱이 임의 확인 완료로 바꾸지 않는다.
- 영향: FR-025~027, NT-021~023, LT-019, AC-018.

## D03 — 실제 문구별 성격

- 상태: 관리자 최종 승인 반영 완료(2026-10-26).
- 결정 근거: 사용자가 전달한 생산운영팀 교대 책임자의 추가 11종 승인과 앞선 확인 대기 문구 승인 1종.
- 확정 표: note-classification-proposal.md. 기존 추천표 경로를 보존하고 내용은 승인 명세로 갱신했다.
- 분류: 후속 확인·지속 관찰·참고 정보·분류 확인 필요. 앞의 두 분류는 모두 인계 대상이다.
- 주요 변경: N03/N05/N06은 지속 관찰, N07은 참고 정보, N08/N12는 분류 확인 필요, N11은 후속 확인(자료 누락 여부 확인 필요). 나머지 후속 확인도 승인됐다.
- 모든 문구의 조치 완료 여부는 미확정이다. 분류 확인 필요는 처리 정책 승인이 완료된 상태이며 문장 의미가 확정됐다는 뜻은 아니다.
- 신규/미등록 문구는 분류 확인 필요로 제공하며 단순 키워드나 외부 AI로 확정하지 않는다.
- D01의 기간·D02의 관계 불일치 제한은 유지한다. 후속 확인/지속 관찰이어도 최근 범위·직접 LOT 참조·설비 일치 조건을 충족해야 메모만으로 LOT를 신규 편입한다.
- 영향: FR-023~027/029~030, NT-010~016, LT-013/015, UI-003/005/015~016/020, AC-019/021~022/031~034.
- D03 자체의 미해결 분류 승인 항목은 없다. 새 문구는 별도 확인하며 후속 재검토에서 발견된 조건 조합은 D06으로 관리한다.

## D04 — 불완전 입력

- 상태: 사용자 확정.
- 답변: “읽을 수 있는 부분만 제공하고 불완전 결과임을 명시”.
- 반영: 필수 파일/열 누락·일부 행 파싱 실패에도 읽을 수 있는 자료 결과를 제공하고 오류/누락 범위를 표시한다. 판정할 수 없는 영역을 정상·0건으로 바꾸지 않는다. 복사 요약도 부분 결과임을 명시한다.
- 영향: FR-001/031~034, DT-005~006, UI-023~024, AC-025/026.

## D05 — 최근 24시간 경계

- 상태: 사용자 확정.
- 답변: “정확히 24시간 전 기록은 제외”.
- 반영: 메모 작성과 재발 발생 시각은 `(T-24시간,T]` 범위. 가용 시각 T 자체는 포함한다. 26일 08:00 조회에서 25일 08:00은 제외, 25일 08:00:01은 포함한다(그 외 가용 조건 충족 시).
- 영향: FR-004~005/014/023/025, DT-016, AL-032, NT-001, AC-024.

## D06 — 취소·보류 미확인과 확정 후속 업무의 동시 성립

- 상태: 관리자 최종 승인 반영 및 변경 영향 범위 재검증 완료(2026-10-26).
- 경위: 기존 문구가 확정 후속 업무와 보류 관련 미확정을 LOT 전체의 하나의 상태로 혼동할 수 있어 관리자에게 질의했다. 사용자가 답변을 전달했다.
- 승인: 메모 기반 인계 대상은 확정, 후속 업무는 있음. 보류 수량은 미확인, 보류 수량 관련 후속 확인 필요성은 미확정이다. 조치 완료도 미확정이고 메모 연결만으로 긴급을 확정하지 않는다.
- 금지: 승인 메모로 업무가 확인된 LOT 전체에 후속 확인 여부 미확정을 붙이지 않는다.
- 보류 0 전환: 나중에 보류 수량이 0으로 확인돼도 유효한 메모의 후속 업무가 남아 있으면 메모 기반 인계를 유지한다.
- 근거: 당시 가용 LOT 스냅샷과 직접 연결된 메모 원본을 함께 제공한다.
- 기존 기간·직접 LOT 참조·설비 일치 기준은 유지한다. 상태 축을 분리하는 승인이지 조치 완료/관계 승인 기능을 추가하는 요청이 아니다.
- 작업: [MDQ-001 완료 기록](manager-questions.md). [변경 영향 검증](validation-d06.md).
- 영향: FR-019/022/025/028~030, LT-015~017, UI-017/020, 기획 조건 C, AGENTS의 취소 NULL 규칙, AC-035/038/039.
- 검증 범위: 이번 답변의 인계/보류 독립 판정·보류0 유지·화면/요약만 재대조했다. 이미 검증한 알람·시점·문구 분류·CSV 집계는 반복하지 않았다.

## D07 — 간결/전체 요약과 표시 순서

- 상태: 관리자 최종 승인(2026-10-26), 명세 선반영 후 구현·자동47건·브라우저5단계 확인 완료. 이전 QA Q1은 해결됐다. 최종 현장 사용성은 관리자 검토 대기.
- 기본 간결 요약은 영역별 상위 5건, 최대15건. 잔여 건수와 전체 상세 안내를 포함한다. 별도 전체 상세 조회/복사를 제공한다.
- 생산/현장은 보류 LOT→진행 LOT→승인 메모 LOT→기타 후속 현장 업무, 같은 순위 최신 확인 가능 시각이 빠른 순. LOT 최고 조건 한 번만 표시, 모든 사유/미해결 HIGH 연결은 보존한다.
- 데이터 확인은 충돌 알람→수량/revision 모순→필수값 누락→관계 불일치→기타. 같은 유형 최신 확인 가능 시각이 최근인 순.
- 간결 항목도 ID/상태/사유/다음 확인/근거를 보존한다. 전체 상세는 생략 없음.
- 1~2분 읽기 목표와 5단계 실제 브라우저 확인을 승인했으나 최종 현장 사용성 승인은 아직 아니다.
- 영향: FR-036~042, 상세06 SU-001~023, AC-040~047, 기획 조건G 및 tasks T015~020.

## 결정을 새로 만들지 않고 유지하는 한계

수량 합계 등식, 실제 피해, 조치 완료, 최초 이력 이전 전체 상태는 미확정 또는 확인 불가로 유지한다. 이미 범위 밖/보장 불가로 합의됐으므로 같은 정보를 다시 요구해 구현을 막지 않는다.

기술 스택·입력 UI·성능 수치·브라우저 지원 범위는 plan 단계의 결정이다. 이번 명세에서는 임의로 고정하지 않는다. 정식 constitution 비준일은 별도 메타데이터 TODO이며 제품 업무 규칙으로 오인하지 않는다.
