## 검사 스크립트

- `scripts/static-check.mjs`: ESLint 실행, HTML/JS ID 연결, 정적 로컬 import/re-export/문자열 dynamic import의 모듈 누락·순환 참조 검사. 오류나 경고가 있으면 종료코드1, 통과하면0을 반환한다. 검사 자체의 실행 오류도 성공으로 처리하지 않는다.
- `eslint.config.mjs`: ESLint10.13.0 권장 규칙과 예외 처리 관련 규칙. 구문 오류, 미정의/미사용 값, 위험한 optional chaining/finally/Promise executor, eval 등 검사.
- `scripts/static-rules.mjs`: 프로젝트 전용 AST 규칙. 계층 의존성, 도메인/데이터/뷰의 현재시각 직접 조회, 허용하지 않은 HTML 대입, Math.max/min의 무제한 인자 펼침, 비동기 이벤트 리스너 경계를 점검한다.
- `tests/static-rules.test.mjs`: 각 규칙에 위반 코드와 정상 코드를 넣어 실제 검출/통과 여부를 확인한다. renderer와 같은 이름의 임의 함수를 신뢰하지 않는지도 확인한다.

ESLint는 개발 검사 의존성으로만 설치했고 lockfile로 버전을 고정했다. 애플리케이션 실행에는 외부 npm 패키지가 필요하지 않다. 도구 기준: [ESLint 공식 시작 안내](https://eslint.org/docs/latest/use/getting-started/), [설정 문서](https://eslint.org/docs/latest/use/configure/configuration-files).
